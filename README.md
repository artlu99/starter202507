# React + TypeScript + Vite

This template provides a minimal starter to get React working in Vite with HMR.

## UX + DX batteries included

- TailwindCSS v4 + DaisyUI 
- Hono backend, with full end-to-end type safety
- Tanstack React Query wrapped around itty-fetcher
- Zustand state management
- Wouter minimalist routing
- valibot (Zod-compatible) parsing + validation
- Framer animations
- lefthook pre-commit hooks
- Biome linting

### Common items to add

- auth (web2 or web3)
- database (*e.g.*, Neon, Turso, Evolu)
